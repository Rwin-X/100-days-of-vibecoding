# ⚡ HashForge

> **Hash Identifier & Multi-Algorithm Generator**

A minimal, dependency-free hashing utility built with Python & Tkinter.

### ✦ Features

* 🔍 **Identify** — detect possible hash algorithms by format, length & charset
* ⚡ **Generate** — generate hashes using multiple algorithms
* 📋 **Copy** — copy individual or all generated digests
* 🖥️ **GUI** — dark cyberpunk-inspired interface
* 🧩 **Zero Dependencies** — Python standard library only

### 🛠️ Built With

`Python` · `Tkinter` · `hashlib` · `zlib` · `re`

### 🚀 Run

```bash
python hashforge.py
```

### ⚠️ Note

Hash identification provides **candidates, not certainty**.
Multiple algorithms can produce the same output length.
